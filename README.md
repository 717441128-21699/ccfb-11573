# 天车操作模拟训练系统

网页版桥式起重机（天车）操作模拟器，用于新学员上岗前训练（如"模拟器满 20 小时方可上岗"的培训要求）。
TypeScript + 原生 WebGL2，无任何运行时依赖。

## 运行

```bash
npm install
npm run dev        # 开发（默认 http://localhost:5173）
npm run build      # 产物到 dist/，可任意静态托管
npm run preview    # 预览构建产物
npm run test:physics  # 物理模型冒烟测试
```

## 功能

- **选车间 / 选吊物**：3 个车间（轧钢、模具、精整，障碍物布局不同）；3 种吊物——
  钢卷（25t，C 型钩单点）、钢板（12t，四腿链条、6m 长件）、模具（8t，四点吊），
  重量、吊点（索具长度）各不相同，摆动特性随之不同。
- **双摆物理**：吊点(小车)→吊钩→吊物 两级摆，Verlet 积分 + 单侧绳约束（绳只拉不推），
  物理步长 1ms；起升收绳后摆动周期自然变短（T∝√L，已用测试验证）。
  老司机"跟车稳钩"（逆摆向点动大车/小车）在模型上完全可练。
- **操作**：键盘（A/D 大车、W/S 小车、R/F 起升、Shift 微动）或标准手柄
  （左摇杆大车/小车、右摇杆或 LT/RT 起升、LB 微动）。鼠标拖动转视角、滚轮缩放、C 键跟随吊物。
- **评分**：摆角持续超 5° 每秒扣 1.5 分（上限 40）；距障碍 <0.5m 报警每次扣 3 分（声光报警）；
  碰撞直接判失败；超标准用时每 10s 扣 1 分（上限 15）；落点偏差每 0.1m 扣 1 分（上限 10）。
  吊物在绿色垛位内落稳（摆角 <3°）即完成。
- **教练成绩单**：按学员记录每次训练的最大摆角、用时、报警/碰撞次数、得分与评级；
  按吊物类型聚合碰撞率与平均摆角，自动标出"最易出事"的吊物。数据存 localStorage。

## 代码结构

```
src/
  config.ts    车间布局、障碍物、吊物参数
  physics.ts   大车/小车/起升运动学 + 双摆 Verlet + 碰撞/报警检测（1ms 步长）
  render.ts    WebGL2 渲染器（盒/圆柱/网格网格体、方向光、轨道相机）
  scene.ts     车间、吊车、吊物、垛位的场景绘制
  input.ts     键盘 + Gamepad API
  scoring.ts   计分与评级
  ui.ts        菜单 / HUD / 结算 / 教练成绩单
  audio.ts     报警蜂鸣与结果音效（WebAudio）
  main.ts      主循环：1ms 定步长物理累加器，渲染 60fps 解耦
scripts/
  physics-check.ts  物理冒烟测试（摆周期、绳长影响、碰撞、报警、落地）
```

## 可调参数

- 机构速度/加速度：`src/physics.ts` 顶部 `BRIDGE / TROLLEY / HOIST`
- 摆动阻尼：`physics.ts` 中 `dampHook / dampLoad`（指数时间常数，秒）
- 报警距离、扣分规则：`physics.ts`（0.5m）、`scoring.ts`
- 车间与吊物：`src/config.ts`
