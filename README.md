# 天车操作模拟训练系统

面向钢厂新员工上岗培训的网页版天车（桥式起重机）操作模拟器。TypeScript + 原生 WebGL2 实现，无运行时第三方图形依赖。

## 启动

```bash
npm install
npm run dev        # 开发模式（Vite，默认 http://localhost:5173）
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 预览生产构建
npm test           # 运行 26 项物理 / 碰撞 / 评分单元测试
```

浏览器要求：支持 WebGL2 的现代浏览器（Chrome / Edge 100+ 等）。推荐使用键盘，或连接标准游戏手柄（Xbox 映射），平板可用屏幕按钮。

## 操作方式

| 动作 | 键盘 | 标准手柄 | 触屏 |
| --- | --- | --- | --- |
| 大车（桥架 X 向） | A / D 或 ← / → | 左摇杆水平 | 大车 ◀ / ▶ |
| 小车（Z 向） | W / S 或 ↑ / ↓ | 左摇杆垂直 | 小车 ▲ / ▼ |
| 起升 / 下降 | Q / E | LT / RT（或 LB / RB） | 起升 / 下降 |
| 暂停 | P | — | 顶部按钮 |

鼠标左键旋转视角、滚轮缩放、右键平移；顶部可切换全局 / 跟随吊物视角。

## 物理模型

- **双摆模型**：吊钩组（第一级，绳长 L1）与吊物（第二级，吊索等效长 L2）各自一个摆角，X / Z 两轴解耦。基于小角度拉格朗日线性化方程，质量矩阵随绳长实时变化，绳长变化通过 `Ṁω` 项自然产生 `2L̇ω` 科氏加速度。
- **绳长与周期**：固有频率 ≈ √(g/L)，放长钢丝绳摆动周期变长（有单元测试验证）。
- **固定步长 1 ms**：主循环用累加器保证物理步长恒为 1 ms，渲染按 60 FPS 在相邻物理快照间线性插值。
- **驱动模型**：大车 / 小车 / 起升均为速度斜坡模型，带加速度限值与行程 / 绳长钳制。
- **阻尼**：综合空气阻力与机构摩擦的等效线性阻尼，自由摆动包络时间常数约 12.5 s，贴近真实天车经验。

## 考核规则

- 吊物摆角超过 **5°**：按超限累计时长扣分（每秒 2 分）
- 与障碍物净距不足 **0.5 m**：触发报警（每次 3 分），画面中吊物变黄并弹出报警条
- **碰上障碍物 / 边界**：本次作业直接判失败
- 落点偏差、落地摆角、超时均有对应扣分；满分 100，评级优秀 / 良好 / 合格 / 不合格
- 安全落垛要求：对准垛位（≤0.4 m）、落地水平速度与摆角均在限值内

## 教练端

首页进入"教练端 / 成绩单"，数据保存在浏览器 localStorage：

- **按吊物类别统计**：钢卷 / 钢板 / 模具各自的练习次数、碰撞数、报警数、平均最大摆角、失败率、平均分——用于判断哪类吊物最容易出事
- **按学员统计**：累计训练时长与 **20 小时（72000 秒）上岗门槛**达标情况
- 逐次练习明细（摆角、用时、碰撞、分数、评级），可导出 CSV 供存档打印

## 目录结构

```
src/
  types.ts              公共类型与车间/吊物/障碍数据结构
  config.ts             两个车间、三类吊物、机构限值配置
  physics/
    math3d.ts           向量 / AABB / 4x4 矩阵
    pendulum.ts         双摆单轴模型与固有频率解析解
    collision.ts        AABB 碰撞、0.5m 报警、行程边界
    simulation.ts       天车仿真实体（1ms 步进、指标、落垛判定、渲染插值）
    *.test.ts           物理与集成测试

    renderer.ts         WebGL2 渲染器（盒子/圆柱网格、方向光、透明通道）
    scene.ts            车间场景装配、绳段朝向、轨道相机
  input.ts              键盘 / 手柄 / 触屏统一输入
  scoring.ts            评分、成绩单存储与统计聚合
  hud.ts                仿真页仪表
  main.ts               页面流转与固定步长主循环
```

## 培训要点（稳钩手法）

双摆在受迫加速后会出现吊钩与吊物两级摆动。老司机的"跟车稳钩"在本模拟器中可复现：吊物向前摆出时，同向点动对应机构给吊点一个同向加速度，摆回时回带，利用双拍相位差逐级消耗摆幅；落钩阶段绳变长、周期变慢，更需要提前稳钩并低速下放。
